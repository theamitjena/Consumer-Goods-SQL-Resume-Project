# Atliq Hardwares SQL Analysis (CodeBasics Resume Project Challenge #4)

This repository contains my solution for **CodeBasics’ Unguided Resume Project Challenge #4**: solving 10 ad-hoc SQL requests for **Atliq Hardwares**, a computer-hardware company, and presenting the results in a narrated video.

---

## 🔍 Project Overview

- **Client**: Atliq Hardwares (computer-hardware retail & distribution)  
- **Challenge**: 10 real-world ad-hoc requests, including year-over-year product growth, sales performance, and channel contributions  
- **Deliverable**:   
  1. Audio-narrated video presentation  
  2. All SQL queries used for analysis
